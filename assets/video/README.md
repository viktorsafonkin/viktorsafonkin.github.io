# Видео работ

Сюда кладутся короткие петли, сгенерированные по `prompts.md`.

Имя файла — по номеру работы: `05-nochnye-igry.mp4`, `01-vremya.mp4` и так далее.
Поддерживаются `.mp4`, `.webm`, `.mov`.

После добавления файлов:

```powershell
python tools/build_videos.py   # обновит assets/js/videos.js
python tools/inline.py         # пересоберёт самодостаточные версии
```

Карточка сама подхватит видео: оно появится поверх фрагмента и будет проигрываться
при наведении, а вне экрана — останавливаться. Если видео нет, карточка живёт как раньше.
