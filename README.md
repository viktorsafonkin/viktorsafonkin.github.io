# Виктор Сафонкин — сайт-каталог

Тёмный музейный сайт художника: главная с избранными фрагментами, биографией и хроникой
выставок, отдельный каталог всех 23 работ с лайтбоксом.

## Структура

```
safonkin/
├── index.html                  главная: hero, избранное, художник, выставки, коллекции, контакты
├── works.html                  каталог: все 23 работы
├── index-inline.html           то же, но картинки и стили внутри файла (для пересылки)
├── works-inline.html           каталог в самодостаточной версии
├── assets/
│   ├── css/style.css           вся вёрстка: тёмная тема, масонри, лайтбокс
│   ├── js/works.js             данные о работах (название, файл, размеры)
│   ├── js/app.js               лайтбокс, клавиатура, меню, шапка
│   ├── works/*.jpg             23 полотна целиком (для просмотра)
│   ├── frag/*.jpg              23 фрагмента — то, что видно в галереях
│   └── data/                   works.json и frags.json — данные для скриптов
├── tools/inline.py             сборка самодостаточных версий
└── README.md
```

## Дизайн

Угольный фон, современная типографика: **Onest** в заголовках (геометрический гротеск,
плотный трекинг, капс) и **Inter** в тексте. Тонкие линии, единственный цветовой акцент —
глубокая кровь `#8E1F17`, которая рифмуется с красным платьем, «Красным смехом» и розовым
деревом. В hero имя набрано тонкими весами (200 и 100) — почти волосяными линиями. Никаких скруглений
и «карточек».

**Галереи — не сетка квадратов, а фрагменты.** Для каждой работы автоматически вырезан
кроп: увеличение около 2×, три пропорции вперемешку (4:5, 1:1, 3:2). У ключевых работ
точка фокуса задана вручную — красное платье «Ночных игр», маска «Красного смеха»,
крона «Вечной весны», группа женщин во «Времени». Фрагмент даёт то, что в живописи важнее
общего плана: фактуру мазка, лицо, жест. Полотно целиком открывается по клику в лайтбоксе,
поэтому кроп не теряет связи с картиной.

- **Hero** — «Ночные игры» во весь экран, поверх — имя крупным гротеском.
- **Избранное** — 8 фрагментов в масонри, при наведении кроп слегка отъезжает.
- **Художник** — цитата из манифеста и биография с датами.
- **Хроника** — 25 выставок с 1992 по 2025 и награды.
- **Коллекции** — музеи сеткой, частные собрания отдельной строкой.
- **Контакты** — галерея Омельченко.

## Лайтбокс

Клик по работе (или Enter/Space) открывает полотно целиком: Esc — закрыть, стрелки —
листать, клик по фону — закрыть. Счётчик `05 / 23`, фокус возвращается на карточку.

## Локальный просмотр

Открыть `index.html` двойным щелчком (рядом должна лежать папка `assets`). Если нужен сервер:

```powershell
python -m http.server 5500
```

Если файл нужно переслать или открыть в просмотрщике без доступа к соседним папкам —
используйте `index-inline.html` / `works-inline.html`: там картинки, CSS и JS зашиты внутрь.

Пересобрать их после правок:

```powershell
python tools/inline.py
```

## Как добавить работу

1. Положить полотно в `assets/works/` (`24-nazvanie.jpg`).
2. Вырезать фрагмент в `assets/frag/` (`frag-24.jpg`), пропорция любая из 4:5, 1:1, 3:2.
3. Дописать объект в `assets/js/works.js` и карточку в `works.html`.

## Живые фрагменты

Поверх кропов в «Избранном» работает тонкий слой частиц на canvas — у каждой работы свой сюжет:

| Работа | Сцена |
|---|---|
| Время | искры поднимаются от огня |
| Ночные игры | ночной туман ползёт по низу |
| Вечная весна, Розовый ветер | лепестки падают и кружатся |
| Красный смех | потёки краски медленно стекают |
| Марсианский вокзал, Колыбельная | пыль в воздухе |
| Аномальное животное | туман |

Плотность минимальная — 5–16 частиц на карточку, прозрачность 5–25 %, поэтому движение
читается как «картина дышит», а не как анимация. Анимация запускается только когда карточка
в зоне видимости (`IntersectionObserver`) и останавливается при уходе из неё и при скрытой
вкладке. При `prefers-reduced-motion` частицы не создаются вовсе.

### Мимика

У двух работ сделаны крупные планы и поверх них — тонкий слой мимики (canvas):

- **«Ночные игры»** — девушка моргает: веки закрываются за 150 мс раз в 3–8 секунд,
  иногда двойным морганием. Координаты глаз выверены по кропу (0.437, 0.565) и (0.522, 0.565).
- **«Время»** — две поющие женщины: рты приоткрываются в ритме 2.4 с, со сдвигом фазы.

Наложение сделано размытыми эллипсами с низкой прозрачностью, чтобы читалось как движение
лица, а не как «стикер». Настоящая мимика (как в видео) потребовала бы нейросетевой
image-to-video — здесь же принципиально важна лёгкость: страница не тянет ни одного видеофайла.

## Фоновый звук

Внизу справа — кнопка «звук». Музыка не файл, а синтез на **Web Audio**: четыре расстроенных
осциллятора-дрона (55, 82.4, 110, 164.8 Гц) через lowpass и свёрточный ревербератор, поверх —
коричневый шум, отфильтрованный полосовым фильтром с медленной LFO (это «ветер»), и редкие
колокольчики в ля-миноре (ноты 110–293 Гц), всплывающие раз в 9–23 секунды.

- Автоплей не навязывается: `AudioContext` создаётся только по клику (политика браузеров).
- Громкость поднимается плавно за 3 секунды, гасится за 1.3.
- При скрытии вкладки контекст приостанавливается (`visibilitychange`).
- Файлов нет — страница не потяжелела ни на килобайт аудио, и нет вопросов с правами.

## Видео (опционально)

Промты для генерации лежат в `prompts.md`. Готовые клипы кладутся в `assets/video/`
с именем по номеру работы (`05-nochnye-igry.mp4`), затем:

```powershell
python tools/build_videos.py   # manifest assets/js/videos.js
python tools/inline.py         # пересобрать inline-версии
```

Код подхватывает видео автоматически: слой `<video>` появляется поверх фрагмента, играет
по наведению, останавливается при уходе курсора и вне зоны видимости. Если файла нет —
карточка работает как раньше, ничего не ломается.
